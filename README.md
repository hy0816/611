# 📚 國一上學習網

七年級上學期的互動式學習網站，共七科：**地理、歷史、公民、生物、數學**（翰林版）與 **國文、英文**（康軒版）。每一科都有重點整理、名詞卡、練習題、三次段考測驗、全冊模擬卷，以及大量可操作的互動圖；數學每個單元另有「無限練習產生器」。

全部是純 HTML / CSS / JavaScript，**不需要安裝、不需要伺服器、也不需要網路**，雙擊就能使用。

---

## 快速開始

1. 用瀏覽器（建議 Chrome、Edge）開啟根目錄的 **`index.html`**（課程主頁）。
2. 點選任一科目卡片即可進入該科課程；課程頁左上角的「🏠 課程主頁」可回到主頁。
3. 也可以直接開啟各科資料夾裡的 `index.html`。

> 測驗的最佳成績、深淺色設定存在瀏覽器的 localStorage，只保存在這台電腦、這個瀏覽器中。

## 如何修改內容

所有內容都在各科的 `data/` 資料夾中，用文字編輯器（如 VS Code）即可修改。

### 章節檔格式

```js
window.CHAPTERS.push({
  id: 'ch2',            // 網址用的代號，不可重複
  no: 1,                // 排序用的數字
  label: '第 1 章',      // （選填）顯示名稱，省略時自動顯示「第 no 章」
  mark: '1',            // （選填）側欄圓圈內的文字
  icon: '🏺',
  title: '史前臺灣與原住民文化',
  summary: '一句話簡介',
  notes: `<h2>…</h2> … 可直接寫 HTML …`,
  cards: [
    ['名詞', '解釋'],
  ],
  quiz: [
    { q: '題目', o: ['選項A', '選項B', '選項C', '選項D'], a: 1, e: '解析' },
  ]
});
```

### 新增一題練習題

在該章的 `quiz` 陣列加入一行即可：

```js
{ q: '臺灣最長的河川是？', o: ['淡水河', '高屏溪', '濁水溪', '大甲溪'], a: 2, e: '濁水溪約 187 公里。' },
```

- `a` 是正確答案的位置，**從 0 開始算**（0 = 第一個選項）。
- 選項請固定 **4 個且不重複**；畫面上會自動打亂順序，不用擔心答案都在同一個位置。
- 題目、選項、解析是**純文字**（會自動跳脫 HTML）；數學的上標請用 ²、³、⁻ 等字元。
- 可加上 `src: '講義'`，題目旁會顯示「講義」標籤。

### 筆記中的特殊樣式

```html
<div class="box tip">考試重點的內容</div>     <!-- 黃底「考試重點」 -->
<div class="box memo">記憶口訣的內容</div>    <!-- 藍底「記憶口訣」 -->
<div data-widget="名稱"></div>                <!-- 插入互動圖 -->
<span class="frac"><span>3</span><span>4</span></span>   <!-- 數學：上下排列的分數 -->
```

互動圖的名稱定義在 `assets/*-widgets.js` 中的 `W['名稱'] = …`。

### 段考範圍與模擬卷

- 段考範圍預設「每兩章一次」，`no` 小於 1 的章節（如英文 Get Ready）併入第一次段考。
- 要自訂範圍，在該科 `index.html` 的 `window.COURSE` 加上 `terms`，例如數學：

```js
terms: [['u1', 'u2', 'u3', 'u4'], ['u5', 'u6', 'u7'], ['u8', 'u9']]
```

- 模擬卷在 `data/exam-sets.js`，每題比練習題多一個 `ch`（出處章節的 id），例如：

```js
{ ch: 'ch3', q: '題目', o: ['A', 'B', 'C', 'D'], a: 0, e: '解析' },
```

### 新增一章

1. 在 `data/` 新增章節檔（例如 `ch7.js`）。
2. 在該科 `index.html` 加上 `<script src="data/ch7.js"></script>`。

### 課程主頁新增或啟用科目

根目錄 `index.html` 的 `COURSES` 設定每個科目一筆：

```js
{ group: '社會', dir: 'society-civics', cls: 'civ', icon: '⚖️', name: '公民', sub: '翰林版・社會領域・公民',
  ready: true, desc: '一段簡介' },
```

- `sub` 會顯示在科目名稱下方，用來標示版本（翰林／康軒）。
- `ready: false`：顯示為虛線的「籌備中」卡片，不能點選；課程做好後改成 `true` 即可。
- 每一列放哪些領域由 `ROWS` 決定，目前是：社會（地理、歷史、公民）／語文（國文、英文）／數學・自然。

## 🗺️ 課外遊戲：看地圖猜國家（world-quiz/）

與課綱無關的世界地理遊戲，收錄 196 個國家（中文名＋英文名、首都、洲別、國旗）。

| 模式 | 玩法 |
|---|---|
| 📍 地圖找國家 | 給國名，在空白地圖上點出位置；三次機會，計時、計算一次答對率（類似 Seterra）。 |
| 🔦 看標示選國名 | 地圖亮起一國，四選一。 |
| 🧩 輪廓猜國家 | 只看形狀，輸入國名（有自動完成）；猜錯顯示距離、方向與接近度，六次機會。有「每日挑戰」（每天一題、可複製結果）與無限練習（類似 Worldle）。 |
| 🚩 國旗、🏛️ 首都 | 看國旗選國家、看國家選首都。 |

- **範圍與難度**：可選全世界或單一洲；簡單＝常見大國、普通＝再加中型國家、困難＝全部。題數 10／20／全部。
- **紀錄**：各模式最佳成績、每日挑戰連勝、最常答錯的國家（存在瀏覽器 localStorage，鍵名開頭為 `wq:`）。
- **資料**：`data/countries.js` 是國家表（`[地圖名稱, 中文, 英文, 首都, 洲, ISO 代碼, 難度, 別名]`），修改難度或譯名改這裡即可；`data/countries-50m.js` 是 1:50m 國界；`flags/` 是國旗 SVG（[flag-icons](https://github.com/lipis/flag-icons)，MIT 授權）。
- 遠離本土的海外領地（如法屬圭亞那、夏威夷）不列入輪廓與取景；若某國輪廓不理想，可在 `COUNTRY_TRIM` 指定經緯度範圍。
- 吐瓦魯（Tuvalu）因地圖資料中沒有其形狀，未列入題庫。

## 共用元件

- **`assets/app.js`**：各科共用同一份主程式，透過 `index.html` 中的 `window.COURSE` 設定區分科目（標題、圖示、成績存放的鍵名）。修改時請各科一起更新。
- **練習產生器（數學）**：`math/assets/math-core.js` 提供分數運算、算式解析、逐步計算與 `makePractice()`；各單元的出題規則寫在 `math-widgets.js` 的 `gen-u1` … `gen-u9w`。
- **練習工具（公民、國文、英文）**：`assets/practice.js` 提供 `makePractice()`（選擇或輸入作答的題目產生器，可加 `say` 播放英文發音）、`makeBuilder()`（排句子）、`makeSpot()`（找錯字）、`makeOrder()`（排順序）、`makeChoiceSet()`（情境選擇題）。
- **分類練習、地圖、時間軸**：`makeSorter()`、`pointMap()`、`makeTimeline()`（歷史）、`makeDiagram()`、`makeOrder()`（生物）等可重複使用。

## 資料來源與注意事項

- 地理、生物、數學依翰林版七年級上學期編排；**歷史**依「重點速讀祕笈」講義（第二篇）調整章節。內容為自行整理，使用前建議與課本核對。
- **公民（翰林）、國文、英文（康軒）** 目前採「通用架構」：依七上該學的觀念與能力分章（例如國文的修辭、標點，英文的文法），**不是逐課對應課本的課次**。若要對齊課本，可依課本目錄調整 `data/` 的章節（國文可加入各課課文、作者、注釋；英文可加入各課單字與對話）。
- 部分地圖內容為**示意**（例如山脈、河道、板塊交界、原住民族分布位置），畫面上已標註。
- 生物、地理的部分數據（如各城市氣候圖）為約略值，僅供比較趨勢。
- 地圖資料：Natural Earth（經 [world-atlas](https://github.com/topojson/world-atlas)）、[taiwan-atlas](https://github.com/dkaoster/taiwan-atlas)；繪圖使用 [D3.js](https://d3js.org/) 與 [topojson-client](https://github.com/topojson/topojson-client)，皆已存在 `assets/vendor/` 與 `data/`，可離線使用。
